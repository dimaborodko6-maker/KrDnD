# Historical balance design model

The complete design equations, calibration tables and content-generation instructions now live in [AGENTS.md: balance specification](../AGENTS.md#математический-баланс-и-формулы-спецификация-для-ии-агентов). Maintain that section as the single source for the model.

These are design targets, **not a verified specification of every live value**. In particular, a theoretical clear-wave bonus is not proof that the server awards it. Before changing balance, compare the model with code and tests, establish the intended budget, then update implementation, tests and documentation together. No rebalance is performed by relocating this documentation.

For implementation recipes see [entities.md](entities.md); for current tower timing and thresholds see [tower-combat.md](tower-combat.md). The player introduction is [README.md](../README.md).
