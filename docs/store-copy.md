## Short description

A cooperative tower defense game for your group: create heroes, build from a shared treasury and hold the road while a game master leads the encounter.

## Full description

Gather around one shared battlefield. Choose a hero, select three abilities and coordinate with your team to protect the castle. Build and upgrade towers, hold enemies on the road and time your attacks as the game master advances each round.

The GM can prepare maps, enemy waves, hidden notes, objectives and branching adventures. Run a quick defense using the included starter map, or design a session for your own group.

- Eight built-in heroes and a range of tower upgrade paths.
- Cooperative construction using a shared treasury.
- Dice-based hero abilities and visible combat statuses.
- Enemy/wave and scene-preparation tools.
- English interface and a complete host/player guide.

This download runs on a host computer with Node.js 24 LTS. Other players join in their browsers over the same trusted local network. It includes source files and readable launchers; it is not a standalone EXE or hosted online service.

## Installation text

Extract the ZIP into a writable folder. Install Node.js 24 LTS on the host. Run Start-Game.cmd on Windows, or `sh start-game.sh` from a terminal on macOS/Linux. The first dependency installation needs internet access. Open the address printed by the server, load Roadside Defense — Quick Start from the GM dashboard and invite friends using the host's local network address.

## Limits to disclose

No accounts, GM password or public matchmaking. One shared party per process.
