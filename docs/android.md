# Android APK (Мобильный сервер KrDnD)

В папке `android/` находится автономное приложение Android, которое запускает сервер KrDnD и интерфейс игры прямо на телефоне.

## Архитектура

- **Фоновая служба (`NodeServerService`):**
  - Запускает встроенный движок Node.js (`libnode.so` v18.20.4) в фоновом нативном потоке.
  - Удерживает `WakeLock` (запрет сна процессора), чтобы сервер продолжал работать при выключенном экране.
  - Показывает постоянное уведомление в шторке со статусом и адресом подключения.
  - Распаковывает архив `nodejs-project.zip` в защищённую внутреннюю память приложения (`/data/data/com.krdnd.server/files/nodejs-project`).
  - Сохраняет существующие сохранения (`gamestate_save.json`, `scenes.json`) при перезапусках и обновлениях.

- **Интерфейс хоста (`MainActivity`):**
  - Полноэкранный `WebView` (загружает `http://127.0.0.1:3000/`).
  - Верхняя информационная панель с локальным IP-адресом точки доступа/Wi-Fi и кнопкой быстрого копирования адреса для друзей.
  - Кнопка «🌐 Онлайн» для мгновенного создания интернет-ссылки для игры на расстоянии.
  - Кнопка сворачивания панели для освобождения экрана.

- **Безопасность партии (`server-security.js`):**
  - **Защита мастера:** секретный ключ безопасности (`token`/`key`), передаваемый в URL мастера, исключает захват управления посторонними.
  - **PIN-код комнаты:** 4-значный код комнаты, защищающий вход игроков из открытого интернета (вводится вручную или передаётся в ссылке вида `?pin=1234`).

- **Интернет-туннель (`tunnel-service.js`):**
  - Создаёт защищённый публичный URL (`https://...`) без белого IP и проброса портов.
  - Автоматически выбирает доступный провайдер (Cloudflare Quick Tunnel или встроенный чистый JS-шлюз).

## Сборка через GitHub Actions (в облаке)

Вам не нужно устанавливать Android Studio или JDK на компьютер. Сборка настроена в `.github/workflows/build-apk.yml`:

1. **Ручная сборка по кнопке:**
   - Откройте репозиторий на GitHub.
   - Перейдите во вкладку **Actions** → выберите **Build Android APK**.
   - Нажмите кнопку **Run workflow**.
   - Через 3–4 минуты в результатах запуска появится артефакт **`KrDnD-Server-APK`**, откуда можно скачать готовый `KrDnD-Server.apk`.

2. **Автоматический релиз при создании тега:**
   - Создайте тег версии (например, `git tag v1.0.0-mobile && git push origin v1.0.0-mobile`).
   - GitHub Actions автоматически соберёт APK и опубликует его в разделе **Releases** вашего репозитория.

## Установка и игра на телефоне

### Режим 1: Локальная игра (в одной комнате без интернета)
1. Откройте приложение `KrDnD` на телефоне ведущего.
2. Включите **Точку доступа Wi-Fi** на телефоне.
3. В панели отобразится адрес: `🏠 192.168.43.1:3000`.
4. Нажмите **«📋 Ссылка»** и отправьте игрокам. Они подключаются к вашему Wi-Fi и играют в браузере.

### Режим 2: Онлайн-игра (на расстоянии через интернет)
1. Нажмите кнопку **«🌐 Онлайн»** на верхней панели приложения.
2. Приложение создаст публичный защищённый адрес и сгенерирует 4-значный PIN комнаты:
   `🌐 https://something.loca.lt [PIN: 1234]`
3. Нажмите **«📋 Ссылка»** — ссылка с встроенным PIN-кодом скопируется в буфер.
4. Отправьте ссылку друзьям в мессенджер. Они переходят по ней и сразу подключаются к партии!
